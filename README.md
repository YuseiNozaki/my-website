# Personal Website

個人サイトのソースコードです。

## 構成

```
my-website/
├── index.html        # トップページ
├── style.css         # 共通スタイル
├── main.js           # 共通スクリプト（スクロールアニメーション・ハンバーガーメニュー・メール難読化）
├── img/              # 画像
├── career/           # 経歴ページ
├── research/         # 研究ページ
└── links/            # リンク集
```

## 技術スタック

- HTML / CSS / JS（フレームワークなし）

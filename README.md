# Personal Website

個人サイトのソースコードです。

## 構成

```
my-website/
├── index.html        # トップページ
├── css/style.css     # 共通スタイル
├── js/main.js        # 共通スクリプト（スクロールアニメーション・ハンバーガーメニュー・メール難読化）
├── img/              # 画像
├── career/           # 経歴ページ
├── research/         # 研究ページ
└── links/            # 関連サイト
```

## 技術スタック

- HTML / CSS / JS（フレームワークなし）
